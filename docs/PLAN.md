## 1. Competitor Strategy Summary

### What rentinnovacrysta.com does well (steal this):
| Strategy | Their Tactic | How We Copy |
|----------|-------------|-------------|
| **Per-vehicle pages** | Separate .html for each vehicle type (Urbania, Bus, Mercedes, Harrier) | Create pages for each vehicle category with prices |
| **Pricing transparency** | Full pricing tables on EVERY page, not hidden | Add price tables to fleet + pricing + each vehicle page |
| **Phone/CTA everywhere** | Number in header, every page, every section | Already have — maintain |
| **Footer link farm** | 30+ garage locations + 18+ one-way routes in footer | Add route links + locality links in footer |
| **Locality targeting** | Lists 30+ Bangalore areas in footer | Add locality section + keywords on relevant pages |

### What siddeshwaratravels.in does well (steal this):
| Strategy | Their Tactic | How We Copy |
|----------|-------------|-------------|
| **Route/destination pages** | `/packages/tirupati`, `/packages/mysore` | Create 10+ destination route pages |
| **Footer route network** | 35+ destination pair links in footer | Add comprehensive route footer links |
| **Vehicle diversity** | Shows 30+ vehicle types on homepage | Already have fleet section — expand |
| **Package pricing** | Shows per-vehicle pricing on destination pages | Add specific pricing per route |

### What they BOTH miss (our advantage):
| Gap | How We Exploit |
|-----|---------------|
| **No schema markup** | Add LocalBusiness + FAQPage + Product + BreadcrumbList schema on every page |
| **No AEO answer blocks** | Add 40-80 word answer blocks at top of every service page |
| **Poor design/UX** | Premium design = trust = higher conversion |
| **No blog content** | Create 12+ blog posts for long-tail keywords |
| **No locality pages** | Target "tempo traveller Whitefield", "tempo traveller Marathahalli" |
| **No pricing calculator** | Interactive calculator = higher engagement |
| **No Google Maps/trust** | Maps embed + review schema = higher CTR |

## 4. Technical SEO Checklist

### Every Page MUST Have:
- [ ] Unique `<title>` (50-60 chars, primary keyword near front)
- [ ] Unique `<meta name="description">` (150-160 chars with keyword + CTA)
- [ ] `<link rel="canonical" href="...">` pointing to itself
- [ ] Open Graph tags (`og:title`, `og:description`, `og:image`, `og:url`)
- [ ] Twitter Card tags
- [ ] One `<h1>` with primary keyword
- [ ] `<h2>` and `<h3>` subheadings with secondary keywords
- [ ] Image alt text with keywords (descriptive, not stuffed)
- [ ] Internal links to at least 3 other pages on the site
- [ ] Answer block (40-80 words) at top of content
- [ ] "Updated June 2026" badge

### Site-Wide:
- [ ] `sitemap.xml` — generated after all Phase 1 pages built
- [ ] `robots.txt` — allow all, point to sitemap
- [ ] Google Analytics 4 installed
- [ ] Google Search Console verified
- [ ] 301 redirects for any broken URLs from old site
- [ ] Performance: LCP < 2.5s, CLS < 0.1, INP < 200ms
- [ ] Mobile PageSpeed score 90+

## 5. Schema Markup Requirements

### ALL Pages — TravelAgency Schema
Copy from `index.html` — update `url` field to match current page URL.

### Fleet Page — Product Schema (per vehicle)
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "12 Seater Luxury Tempo Traveller Bangalore",
  "description": "Luxury 12 seater tempo traveller with Maharaja pushback seats, AC, LED TV",
  "brand": { "@type": "Brand", "name": "Khushi Travels" },
  "offers": {
    "@type": "Offer",
    "price": "28",
    "priceCurrency": "INR",
    "priceUnit": "per kilometer"
  }
}
```

### Pricing Page — Product Schema + Offer
Add one `Product` per vehicle row with exact price.

### FAQ on Every Page — FAQPage Schema
Minimum 6 Q&A pairs per FAQ section.

### Every Inner Page — BreadcrumbList
